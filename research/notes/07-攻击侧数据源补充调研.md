# 调研笔记 07：攻击侧训练环境与任务的补充数据源（Cyber Task Factory 扩展）

> 调研日期：2026-09-30。以 Cyber Task Factory 调研为起点（已覆盖：ARVO/OSS-Fuzz/CyberForge/Juliet、CyberGym/ExploitGym/Magma/CGC/BountyBench、syzbot/KernelGPT/kernelCTF、NASimEmu/CyberBattleSim/CALDERA/ART/Metasploitable3、AgentRE-Bench/crackmes-RE、zxcvbn/OMEN/PCFG/Hashcat/JtR；已知评测：cybench/NYU CTF/InterCode-CTF/CyberSecEval/τ²-Bench/BFCL）。本笔记**只补攻击侧**，所有 GitHub 条目经 API 核验存在性/license/stars/最近推送，URL 实测存活。蓝队/防御侧按要求暂缓。

## 2. 针对 LLM/Agent 本身的攻击任务族（新任务族建议）

| 项目 | License | 关键事实 | 落点 |
|---|---|---|---|
| AgentDojo（github.com/ethz-spylab/agentdojo） | MIT，880★，活跃 | NeurIPS 2024；**4 个可执行环境（workspace/travel/banking/web）570 任务** + 间接注入攻击用例；内置"utility 成功 + injection 攻击成功"**双判定**；支持自定义 task suite | 直接生成"攻 agent"训练 episode；双指标 verifier 现成 |
| Agent Security Bench（github.com/agiresearch/ASB） | MIT，308★，活跃 | ICLR 2025；**约 400 场景 / 10 阶段 / ~9 万用例**，5 类攻击（注入/RAG 投毒/工具攻击等） | 大体量扩充源 |
| InjecAgent（github.com/uiuc-kang-lab/InjecAgent） | MIT | 1,054 用例（直接危害/数据外泄 × 直接/工具输出间接注入）；静态数据集 | 数据扩充，需自包工具调用环境 |

**含义**：我方模型是 agentic 模型，"被攻击"是部署常态。把 AgentDojo/ASB 转成训练环境（攻击成功率与正常任务完成率双指标）可同时提升鲁棒性，且与 Cyber Task Factory 的统一任务格式完全兼容（环境+verifier 范式相同）。

## 3. 云与 AD 渗透环境母体（渗透 factory 的新环境域）

- **CloudGoat**（github.com/RhinoSecurityLabs/cloudgoat，BSD-3-Clause，3.7k★，活跃）：Terraform 部署 AWS 场景，**每个 scenario 附官方 cheat sheet（利用步骤）**；verifier 用 IAM/资源状态判定。IaC 参数化 = Procedural World Generation。
- **flaws.cloud / flaws2**（Scott Piper）：免费、无需自建，**每关 5 位 flag 机器可判**；源码未完整开源，社区自动化参考 `kh4sh3i/Cloud-Flaws-CTF`（CC0）。
- **AWSGoat / AzureGoat**（ine-labs，MIT）：漏洞云应用，IaC 一键部署，分模块 flag。
- **Kubernetes Goat**（madhuakula/kubernetes-goat，MIT，5.8k★）：场景化 K8s 靶场，附官方攻击脚本。
- **TerraGoat**（bridgecrewio/terragoat，Apache-2.0）：IaC 错配为主，适合配置类任务靶面。
- **GOAD**（Orange-Cyberdefense/GOAD，GPL-3.0，8.4k★）：Vagrant+Ansible 建 **3 DC 多域 forest**，内置大量攻击路径与官方攻略；重（需虚拟化资源）。
- **BadBlood**（davidprowe/BadBlood，GPL-3.0，2.3k★，2023 停更）：**向域内随机灌数千–数万用户/组/ACL**——与 Procedural World Generation 范式同构，可批量产出多样 AD 拓扑（"GOAD 骨架 + BadBlood 灌数据 + Vulnerable-AD 布漏洞"）。
- **Vulnerable-AD**（safebuffer/vulnerable-AD，MIT，2.3k★）：PowerShell 一键布漏洞配置，轻量可重复。
- 批量编排：**Ludus**（badsectorlabs/ludus，AGPL-3.0，Proxmox range 自动化）。
- 落点：云类做 IaC 参数化批量；verifier = "到达目标对象/flag 文件/权限状态"。

## 4. Web 应用靶场（AppFactory 补充）

- **OWASP Juice Shop**（github.com/juice-shop/juice-shop，MIT，14k★）：**100+ 挑战全部定义于 `data/static/challenges.yml`（85KB 机器可读：key/难度/类别/flag/提示）**，内置评分；`juice-shop/juice-shop-ctf`（MIT）可导出 CTFd/FBCTF/rCTF——**机器可读度全场最高，首选母体**（yml→任务 schema，flag 校验即 verifier）。
- **DVWA**（digininja/DVWA，GPL-3.0，13.7k★）：13 模块 × low/med/high/impossible——难度矩阵即 Mutation 轴；**无内建 flag 体系，verifier 需自建**。
- **Mutillidae**（webpwnized/mutillidae，GPL-3.0）：带 set-then-solve 判定机制，易接 verifier。
- **WebGoat**（license NOASSERTION 未核验；lesson 带内建判分 API）；**bWAPP**（无官方 GitHub，license 未核验）。
- **PortSwigger Academy**：250+ 免费 labs，但条款倾向禁止批量自动化（未核验原文）——**只人工参考，不抓取**。

## 5. 移动安全（新环境域）

- **DIVA Android**（payatu/diva-android，GPL-3.0）：67 挑战，**flag 硬编码于 APK**，verifier 明确。
- **Android-InsecureBankv2**（dineshshetty，MIT）：writeup 齐全。
- **OVAA**（oversecured/ovaa，BSD-2-Clause）：**每类漏洞附官方 exploit 说明**，ground truth 质量高。
- **OWASP MASTG**（CC-BY-SA-4.0）+ **mas-crackmes**（LGPL-3.0）：UnCrackable Level 1–4（Android/iOS）→ 现成移动 RE 任务（脱壳/反调试/frida 绕过）。
- **Frida**（wxWindows Library License 3.1）：可同时作任务执行器与 verifier 探针（hook 校验到达漏洞点/取出隐藏 flag）。
- 落点："静态 RE（UnCrackable/DIVA）+ 动态分析（Frida hook 判定）"两类任务；Compile-and-Hide 范式直接适用。

## 6. IoT/固件（新环境域，可选）

- **Firmadyne**（MIT）：官方脚本可重建约 **4.2 万固件下载语料**（论文口径 42,135 下载 / 约 9,486 全系统模拟成功）；再分发需自行抓取。
- **FirmAE**（pr0v3rbs/FirmAE，MIT，活跃）：全系统模拟成功率约 79%，批量"固件→可跑实例"。
- **EMBA**（e-m-b-a/emba，GPL-3.0，3.7k★）：固件分析器，可产出 CVE 候选/硬编码凭据/NVRAM 后门 → 任务素材与 hint 生成器。
- **IoTGoat**（OWASP/IoTGoat，MIT）：OpenWrt 基漏洞固件（213MB），官方 wiki 列漏洞与攻略。
- 落点：规模化瓶颈在模拟成功率与算力；小规模精选做 RE/凭据提取任务，IoTGoat 做可执行靶标。

## 7. 带官方题解的 CTF 存档（"挑战+题解"配对数据，SFT/蒸馏素材 + seed pool）

- **google/google-ctf**（Apache-2.0，5k★，738MB）：目录覆盖 **2017–2026**（quals+hackceler8），挑战源码全公开，官方题解以 README/博客链接形式存在（可得性逐年浮动）。
- **sajjadium/ctf-archives**（MIT，1.6k★，**39GB**）：各大赛挑战附件汇编，规模最大。
- **j00ru/ctf-tasks**（Apache-2.0）：Google Project Zero 历年内核/浏览器挑战，附任务说明。
- **Flare-On**（flare-on.com）：**2014–2025 全部年度挑战 + 官方题解博客公开**（归档密码 "flare" 已核验）；license 未标注，再分发条款未核验——自用可、公开分发需谨慎。
- **Cryptopals**（cryptopals.com）：8 组 64 题免费无注册，**输出确定性强可自建自动判分**（Generate-and-Verify 范式的密码学版）。
- **CryptoHack**（cryptohack.org，13 类目）/ **MysteryTwister C3**（380 题 4 难度）/ **id0-rsa**（~40 题）：免费，题解可得性未核验。
- **picoCTF**：平台开源（MIT，deprecated 2019）；picoGym 数百题在线免费、flag 格式统一；全量历史档案 API 开放性未核验；社区 writeup 仓库多。
- 落点："挑战→agent 解→对照官方题解蒸馏"两阶段任务；google-ctf/ctf-archives/j00ru/Flare-On 是最可靠配对来源。

## 8. 平台 ToS 现状（能否自动抓取）

| 平台 | 结论 |
|---|---|
| Hack The Box | 条款页 403，自动化抓取**未核验**；BoxPwnr 存在不代表官方许可 |
| TryHackMe | 第三方引述其条款限制自动化访问，倾向禁止 |
| Root-Me | CGU 未能核验 |
| CTFtime | API 公开无鉴权，但**仅限数据分析、禁止克隆**；题目内容版权归各作者——只作赛事元数据清洗源 |

**结论**：商业平台一律不做批量抓取，用第 7 节开源存档替代。

## 9. 漏洞补丁/修复数据集（Patch 工作流，与 BountyBench Patch 互补）

- **PrimeVul**（github.com/DLVulDet/PrimeVul，MIT）：约 7k 漏洞函数 + 229k 良性、140+ CWE，**带"漏洞-补丁配对"设计**与 commit 元数据——补丁任务最干净底座。
- **CVEfixes**（secureIT-project/CVEfixes，代码 MIT + 数据 CC BY 4.0）：约 5.5k CVE / 6.5k repo，SQL 库+采集脚本。
- **DiverseVul**（wagner-group，repo 无 license，经 Google Drive 分发，再分发未核验）：793k 函数 / 18.9k 漏洞 / 295 项目，含标签噪声分析。
- **BigVul**（MIT，MSR'20）：约 10.9k 漏洞函数 / 348 CVE；**CrossVul**（无 license）：27 语言。
- **ossf-cve-benchmark**（OpenSSF）：200+ 真实 CVE 含可复现构建。
- 任务形态："给定漏洞 repo → agent 写补丁 → 用 PoC 做修复前后差异测试 + 回归测试"；PoC 生成可套 CVE-Bench 模式；用 PrimeVul paired 设计构造等价对照防捷径。

## 10. 任务运行时/托管

- **CTFd**（CTFd/CTFd，Apache-2.0，6.9k★，活跃）：REST API 覆盖 challenges/flags/submissions 全 CRUD + 插件机制——**批量任务托管、flag 校验、agent 提交记录回收（= reward 信号通道）首选**。
- **RootTheBox**（Apache-2.0，活跃）备选；rCTF（2025 停更）、FBCTF（归档）不推荐；`juice-shop-ctf` 可作"靶场→CTFd 任务"的 ETL 参考。

## 11. 汇总：新数据源 × 五大合成范式映射

| 范式 | 既有来源（原调研） | 本轮新增 |
|---|---|---|
| Reproduction | ARVO、CyberGym | **CVE-Bench（web 层）**、Flare-On/google-ctf 官方题解配对 |
| Mutation | CyberForge、ExploitGym 缓解配置矩阵 | DVWA/靶场难度矩阵、云场景 IaC 参数化 |
| Procedural World Generation | NASimEmu | **BadBlood（AD 拓扑）**、CloudGoat/AWSGoat IaC、FirmAE 固件矩阵、Juice Shop yml 驱动 |
| Compile-and-Hide | AgentRE-Bench | **移动 crackmes（UnCrackable/DIVA/OVAA）**、IoTGoat、Frida 动态验证 |
| Generate-and-Verify | 密码合成 | **Cryptopals（可自动判分密码学）**、AgentDojo/ASB（攻 agent 双指标） |

**新增任务族**：云/AD 横向移动（第 3 节）、移动逆向与动态分析（第 5 节）、固件（第 6 节）、攻 agent（第 2 节）、补丁（第 9 节）、CTF 题解蒸馏（第 7 节）。

**优先级建议**（自动可扩展性 × verifier 强度 × 环境成本 × license 干净度）：
1. **第一梯队（直接改造）**：XBOW Validation Benchmarks、CVE-Bench、Juice Shop、AgentDojo、CTFd runtime——license 干净、verifier 内置、docker 化；
2. **第二梯队（参数化扩产）**：BadBlood+GOAD+Vulnerable-AD（AD 域）、CloudGoat/AWSGoat（云域）、PrimeVul+CVEfixes（补丁域）、FIM 式编译矩阵套移动 crackmes；
3. **第三梯队（素材库）**：ctf-archives/google-ctf/Flare-On（挑战+题解配对，喂 SFT/蒸馏）、Cryptopals（自动判分）、EMBA/FirmAE（精选固件）。

**License 红线**：GPL-3.0 仓库（GOAD/DVWA/DIVA/EMBA/FirmAE/BoxPwnr）可运行使用，衍生代码分发需遵 GPL；Flare-On 再分发条款未核验（自用可）；HTB/THM/PortSwigger/CTFtime 内容一律不批量抓取。
